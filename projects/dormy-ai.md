# Projekt: Dormy AI och automation

## Status
Aktiv intern pitch / affärsutvecklingsspår.

## Kort beskrivning
Ett spår för att positionera Jonas som Dormys go-to-person för AI och automation baserat på lång erfarenhet från butiksgolvet kombinerat med praktisk AI-/automationskompetens.

Idéerna fokuserar på verkliga problem i Dormys vardag: produktfrågor, onboarding, schemaläggning, intranät/kunskapsdatabas och social commerce/reservationer.

## Mål
- Presentera konkreta AI-/automationsidéer för ledning/COO.
- Visa att idéerna kommer från faktisk butikserfarenhet.
- Hålla tonen personlig, ödmjuk och praktisk.
- Inte ge bort för mycket detaljer innan rätt möte/mandat finns.
- Identifiera ett första pilotprojekt som går att testa internt.

## Idéer
### AI-produktbot / intern kunskapsbot
En bot som kan svara på produktfrågor, loft, specs, lagerrelaterade frågor och återkommande kundfrågor.

### Onboardingbot för nya medarbetare
Hjälper nya medarbetare förstå produkter, rutiner, vanliga kundfrågor och intern kunskap.

### AI-schema / personalplanering
Ingestar tidigare scheman, väder, budget, anställda, timmar och skapar förslag för säsong/år.

### Social commerce / boka direkt
Kunder kan reservera kampanjprodukter via exempelvis Instagram-kommentarer eller formulärflöde, och butik kan hantera reservationer.

## Möjlig stack
- Next.js / React för interna UI:n
- Supabase eller annan DB
- OpenAI/OpenRouter/LLM API
- RAG över intern kunskap/product specs
- Kalender-/schemaexport
- Webhook-flöden
- Integrering med befintliga system om tillgång finns

## Viktiga constraints
- Dormy har befintliga system och rutiner som måste respekteras.
- Intern data kräver säkerhet och behörighet.
- Bör börja med pilot, inte stort system.
- Ton i pitch ska vara vardaglig, konkret och inte för teknisk.
- Värdet ska kopplas till butiksnytta, onboarding, tidsbesparing och jämnare kompetensnivå.
