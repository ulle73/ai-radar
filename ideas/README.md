# Ideas

Lägg idébanken här, en markdown-fil per idé.

Det här är för idéer som är tillräckligt intressanta för att sparas, men inte nödvändigtvis aktiva projekt än.

Exempel:

```txt
ideas/golf-training-aids.md
ideas/ai-wedding-planner.md
ideas/cold-email-system.md
ideas/github-trending-radar.md
```

## Rekommenderat format

```md
# Idé: Idénamn

## Kort beskrivning
Vad idén är.

## Problem
Vilket problem den löser.

## Målgrupp
Vem som skulle använda/köpa detta.

## Affärspotential
Kort bedömning.

## Möjlig MVP
Minsta version som kan testas.

## Stack / implementation
Tekniker eller repo-typer som kan vara relevanta.

## Vad GitHub-radarn bör leta efter
Exempel: open-source-verktyg, SDK:er, scraping, AI agents, UI-komponenter, data pipelines.

## Vad som ska ignoreras
Saker som inte passar idén.
```
