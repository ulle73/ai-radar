# ChatGPT-genererade idéer

Här sparas idéer som uppstår från GitHub Radar och ChatGPT-analys.

Rekommenderat arbetsflöde:

```txt
candidates/  -> nya idéförslag som inte är granskade
approved/    -> idéer som är värda att jobba vidare med
rejected/    -> idéer som aktivt ska ignoreras
```

## Viktigt

Alla nya idéer bör först hamna i `candidates/`.

Flytta bara en idé till `approved/` om den faktiskt är värd att spara långsiktigt. Annars riskerar idébanken att bli full av brus.
