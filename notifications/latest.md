# AI Radar – Notifieringar 2026-08-02

## Nytt exceptionellt repo: yc-software/qm

En multiplayer agent-harness för arbete där flera användare kan arbeta separat men samarbeta i kanaler och projekt.

- **Passar:** AI Byggstart / Bygg med AI
- **Konkret användning:** Skapa en agent som hjälper FAIV:s kundsupport med produktfrågor samtidigt som butiksmedarbetare har egna arbetsflöden.
- **Varför:** Kan användas för att bygga en agent som guiderar användare genom byggprocessen med separat arbetsmiljö per användare.
- **Unik skillnad:** Isolerade arbetsmiljöer per användare med delad minne och färdigheter, vilket vanliga agents inte erbjuder.
- **Nästa test:** Testa QM med en demo där två användare samtidigt hanterar olika uppgifter i samma agentinstans.
- **Bedömning:** 89/100, confidence 0.85 – Testa nu
- **Evidens:** Isolerade arbetsmiljöer per användare med separat minne · Stöd för flera modeller (Codex, Claude etc) i samma system · Slack och webbgränssnitt med samma identitet
- **Länk:** https://github.com/yc-software/qm
